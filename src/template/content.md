# Markdown 排版示例

请使用 **Chrome** 或其他现代桌面浏览器。

这里是本地默认模板。你可以直接删除这些内容，粘贴自己的文章。

## 基础语法

### 标题

使用 `#`、`##`、`###` 表示不同级别的标题。

### 列表

- 无序列表 1
- 无序列表 2
  - 二级列表

1. 有序列表 1
2. 有序列表 2

### 强调

**这是加粗文本**

_这是斜体文本_

### 引用

> 这里是一段引用。
> 单个换行也会在预览中显示为换行。

### 表格

| 项目 | 说明 |
| :--- | :--- |
| Markdown | 源文档 |
| HTML | 复制到公众号或知乎的富文本 |

### 代码

```js
const message = "Hello Markdown";
console.log(message);
```

### 数学公式

行内公式：$a^2 + b^2 = c^2$

块级公式：

$$
E = mc^2
$$

## 图片

请使用你自己的 HTTPS 图片链接，或通过图床功能上传图片。

```markdown
![图片描述](https://example.com/image.png)
```

## 试卷检查

如果你在整理试卷 Markdown，可以在顶部菜单「功能」中启用「试卷检查」。
