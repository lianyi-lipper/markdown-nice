# 公众号双封面

入口：**文件 → 公众号封面**。

- 横版（2.35:1）与方版（1:1）分别编辑 Markdown，支持 LaTeX 公式、插入本地图片和粘贴截图。
- 初次打开时会带入正文选区；已有草稿时恢复草稿。点击各栏的“带入正文选区”或“复制另一栏内容”可替换该栏文字，排版设置独立保留。
- 每栏可调整字号、行距、边距、图片最大宽度、水平和垂直对齐；“缩小字号以适应”会将字号逐步减小，最低为 12。
- 预览显示最终的左右拼图。内容接近或超出边缘时仅提醒，仍可按当前预览导出；超出画布的部分会被裁切。公式出错或图片读取失败时不能导出，修改后会重新检查。
- 点击“左右拼接导出”，得到一张 **2680 × 800 PNG**：左侧 **1880 × 800**，右侧 **800 × 800**。分界辅助线和界面控件不进入图片。
- 图片在浏览器内生成。封面草稿与文章正文分开保存；封面只保留最近一份本地草稿。浏览器存储不足时会显示未保存提示，本次编辑仍可导出。
- 外链图片须允许浏览器跨域读取；无法读取时改为粘贴截图或插入本地图片。图片丢失不会静默导出空白区域。

微信公众号后台选择导出的合成图，横版裁左侧，方版裁右侧。
