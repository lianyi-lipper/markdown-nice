# Markdown Nice Local

这是基于 [mdnice/markdown-nice](https://github.com/mdnice/markdown-nice) 的本地自用 fork。

## 功能

- Markdown 实时预览和排版
- 复制到微信公众号、知乎和掘金等富文本编辑器
- 本地 Markdown 语法诊断
- 可选的试卷 Markdown 格式检查
- 单换行按换行渲染

## 本地启动

这个项目依赖较老，建议使用 Node 16。

```bash
node scripts/start.js
```
